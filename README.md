# Prompt frente a Frente

Compara dos versiones de un prompt por líneas. Ve añadidos, eliminados y caracteres sin API de IA, sin cuentas y sin guardar el texto en el servicio.

GitHub Pages: main, raiz. https://ilga25.github.io/prompt-frente-a-frente/

Fuentes estaticas sin dependencias. Pruebas del motor: work/ten-tools/check.cjs. Guia propia, privacidad y sitemap incluidos. Sin garantia de trafico, indexacion, aprobacion publicitaria o ingresos.
