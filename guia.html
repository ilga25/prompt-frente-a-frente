Comparador local de prompts: diferencias línea por línea

Pega dos versiones y revisa las diferencias literales. Esta herramienta no llama a modelos, no necesita claves y no carga publicidad ni scripts externos.

Una línea cambiada son dos operaciones

El comparador conserva las líneas comunes en orden. Cuando reemplazas una frase, puede mostrar una línea quitada y otra añadida. No es una valoración de mejora: únicamente refleja la edición.

Los espacios también cuentan

Dos líneas que se diferencian en un espacio son distintas. Esto ayuda a revisar plantillas, formatos de salida o delimitadores. Los saltos de línea de Windows y Unix se leen de la misma forma.

Cómo usarlo para un experimento

Cambia una instrucción, copia el resultado y conserva por tu cuenta la versión y los resultados del modelo. La herramienta no realiza pruebas A/B ni determina qué versión responde mejor.

Procesamiento local

La comparación se ejecuta en el navegador y no utiliza una API de IA. No guardamos los textos en una base de datos ni los añadimos al enlace. Esta web no incluye publicidad ni bibliotecas externas. El alojamiento sigue recibiendo los datos técnicos necesarios para servir la página.

Límites para mantenerlo ágil

Admite hasta 20.000 caracteres y 250 líneas por versión. Para documentos mayores, divide el texto por secciones. El resultado puede imprimirse o copiarse como texto; comprueba dónde lo pegas si contiene información confidencial.

Ejemplo comprobable

Si una versión tiene las líneas A y B, y la siguiente conserva A pero sustituye B por C, el resultado contiene una línea común, una eliminada y una añadida. No considera equivalentes B y C aunque signifiquen algo parecido.
